# Hermes Skins Pack — 100 Themes
## How to Install

1. Save any YAML block below as `~/.hermes/skins/<name>.yaml`
2. Switch with `/skin <name>` in Hermes CLI
3. Or set default: `hermes config set display.skin <name>`
