# Security Policy

## Supported version

The latest commit on `main` is supported.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/bchop-studio/hermes-skins-pack/security/advisories/new) for security-sensitive reports.

Do not open a public issue for a suspected vulnerability. Include the affected skin or script, reproduction steps, impact, and any suggested fix. Reports will be reviewed before details are made public.

## Scope

Security reports may cover the skin YAML files, the pack validator, installation instructions, repository automation, or behavior triggered when Hermes loads a skin.
